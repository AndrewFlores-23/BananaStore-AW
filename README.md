# Banana Store

Catálogo web de demostración para una tienda de ropa, con estética amarilla y una interfaz inspirada en Liquid Glass.

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicación

Cada actualización enviada a la rama `main` se compila y publica automáticamente con GitHub Pages.

[Abrir el sitio](https://andrewflores-23.github.io/BananaStore-AW/)
